Unit 4

Deadlock Conditions (All 4 must exist)
  • Mutual Exclusion – only one process uses resource
  • Hold & Wait – holds one, waits for another
  • No Preemption – resource not forcibly taken
  • Circular Wait – P1→R1→P2→R2→P1 cycle

Handling Approach
  • Prevention – break one of 4 conditions
  • Avoidance – safe state checking (Banker's algo)
  • Detection & Recovery – detect then recover

💡 Tricks, Mnemonics & Exam Tips

Memory Tricks (Mnemonics)

🔑 Deadlock 4 conditions → "MHNc" = Mutual exclusion, Hold & wait, No preemption, Circular wait
🔑 Process memory sections → "SHDT" = Stack, Heap, Data, Text
🔑 File operations → "CORDCR" = Create, Open, Read, Delete, Close, Rename
🔑 Process states → "NRRWT" = New → Ready → Running → Wait → Terminated
🔑 3 Schedulers → "LSM" = Long-term (Job), Short-term (CPU), Medium-term (Swap)
🔑 Memory hierarchy order → "Registers Come Running Dangerously" = Registers, Cache, RAM, Disk
🔑 Linux distro order → "UFD-FR-CO" = Ubuntu, Fedora, Debian, Fedora, Red hat, CentOS, openSUSE

Common Traps in MCQs

  • PCB is identified by PID — not program name or state
  • Short-term scheduler is the fastest (not most important — that's long-term)
  • In paging: page size MUST equal frame size — NEVER different
  • Internal fragmentation = Fixed partition | External = Dynamic partition
  • ALL 4 deadlock conditions must exist simultaneously — not just 2 or 3
  • Linux was created in 1991 — not 1956 (that's GM's first OS)
  • GUI was invented by Xerox, not Apple or Microsoft
  • Linux is written in C + Assembly (NOT C++); Windows is C++ + Assembly
  • Distributed OS nodes = loosely coupled (not tightly coupled)
  • Thread blocking blocks the entire process; process blocking does NOT block other processes

Pro Exam Strategy

  • Definitions always get marks — always write a crisp 2-line definition first
  • Comparison questions: always use a table (3-4 points minimum)
  • Diagram questions: OS structure, Process states, Paging, Memory hierarchy — draw clearly
  • For "explain with example" → give a real-world example (robot for RTOS, browser tabs for threads)
  • In deadlock questions, write all 4 conditions — examiners check each one
  • Linux question: always mention Linus Torvalds + 1991 + GPL license
  • End long answers with a one-line conclusion for full marks
