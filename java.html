Unit 1
Java Fundamentals & OOP
HIGH PRIORITY
Features of Java
  • Simple — based on C++, no pointers
  • Object-Oriented — everything is an object
  • Platform Independent — bytecode + JVM
  • Portable — same bytecode on any JVM
  • Secured — sandbox, no explicit pointers
  • Robust — garbage collection, exception handling
  • Multithreaded — multiple threads in memory
  • Architecture Neutral — fixed primitive sizes
  • High Performance — bytecode near native code
OOP Pillars
  • Class — blueprint/template for objects
  • Object — instance of a class
  • Inheritance — child gets parent's properties (extends)
  • Polymorphism — same action, different ways
  • Abstraction — hide implementation, show features
  • Encapsulation — wrap data + methods together
Types of Inheritance
  • Single — one parent, one child
  • Multilevel — A → B → C
  • Hierarchical — one parent, many children
  • Multiple — NOT supported via classes (only interfaces)
  • Hybrid — combination (via interfaces)
class Child extends Parent { }
Polymorphism Types
  • Compile-time (Static) — Method Overloading
  • Runtime (Dynamic) — Method Overriding
// Overloading (compile-time) int add(int a, int b) double add(double a, double b) // Overriding (runtime) class Dog extends Animal { void sound() { // different impl } }
Abstraction
  • Abstract class → partial abstraction
  • Interface → 100% abstraction
  • Hide implementation, show only what user needs
  • ATM machine analogy (you press buttons, not see internals)
abstract class Animal { abstract void sound(); // no body void eat() { } // has body }
Encapsulation
  • Wrap data (fields) + methods into a single unit
  • Use private fields + public getters/setters
  • Protects data from direct access
private String name; public String getName() { return name; } public void setName(String n) { name = n; }
Java Platforms
  • Java SE — Standard, core APIs
  • Java EE — Enterprise, web apps
  • Java ME — Mobile/Micro edition
  • JavaFX — Rich Internet Applications
Java Program Flow
  • .java → javac (compiler) → .class (bytecode)
  • JVM reads and executes bytecode
  • Entry point: public static void main(String[] args)
  • Bytecode = platform independent

Unit 3
Java Classes, Constructors & Interfaces
HIGH PRIORITY
Class Declaration
access_modifier class ClassName { data member; method; constructor; nested class; interface; }
  • Class = blueprint / template
  • Class does NOT occupy memory
  • Object occupies memory when created
Constructors
  • Same name as class, no return type
  • Called automatically when object is created (new)
  • Cannot be abstract, static, final, synchronized
  • If no constructor defined, Java provides default
// Default (no-arg) class Car { Car() { } } // Parameterized class Car { Car(String model) { this.model = model; } }
Interface
  • Blueprint of class — only abstract methods
  • Achieves 100% abstraction
  • Supports multiple inheritance
  • Class uses "implements" keyword
  • All methods are by default public & abstract
interface Animal { void eat(); void sleep(); } class Dog implements Animal { public void eat() { ... } public void sleep() { ... } }
Benefits of Inheritance
  • Code Reusability
  • Hierarchical Organisation
  • Polymorphism support
  • Easier Maintenance
  • Method Overriding possible
Unit 4
Control Statements
HIGH PRIORITY
if / else / ladder
if (condition) { // true block } else if (condition2) { // another block } else { // default }
switch
switch(expr) { case val1: // code; break; case val2: // code; break; default: // if no match }
  • break is needed to stop fall-through
  • default runs when no case matches
Loops
  • while — pre-test (may not run)
  • do-while — post-test (runs at least once)
  • for — when iterations are known
  • for-each — iterate arrays/collections
// for-each for (String s : names) { System.out.println(s); }
break & continue
  • break — exits the loop/switch immediately
  • continue — skips current iteration, loop continues
for (int i=1; i<=5; i++) { if (i==3) continue; // skip 3 System.out.println(i); // 1,2,4,5 }
Unit 5
Arrays
Array Basics
  • Fixed size, same data type
  • Indexed from 0
  • Homogeneous — all same type
int[] arr = new int[5]; int[] nums = {1, 2, 3, 4, 5}; int[][] matrix = {{1,2},{3,4}};
Arrays Class Methods
  • Arrays.sort(arr) — ascending sort
  • Arrays.binarySearch(arr, key) — search
  • Arrays.equals(a1, a2) — compare
  • Arrays.fill(arr, val) — fill with value
  • Arrays.copyOf(arr, len) — copy
  • Arrays.toString(arr) — print as string
Array Types
  • Primitive arrays — int[], char[], etc.
  • Object arrays — String[], Person[]
  • Multidimensional — int[][]
  • Jagged arrays — rows of different length
Unit 6
Strings in Java
String Properties
  • Strings are IMMUTABLE — value cannot change
  • String literal uses String Pool
  • new String() creates on heap memory
  • Thread-safe due to immutability
String s1 = "Hello"; // pool String s2 = new String("Hi"); // heap
StringBuffer vs StringBuilder
FeatureStringBufferStringBuilder
Thread-safe✅ Yes❌ No
Synchronized✅ Yes❌ No
SpeedSlowerFaster
Use caseMulti-threadSingle-thread
StringBuffer Methods
  • append(str) — add to end
  • insert(pos, str) — insert at position
  • delete(start, end) — remove chars
  • reverse() — reverse the string
  • capacity() — default 16
StringBuffer sb = new StringBuffer("Hello"); sb.append(" World"); // Hello World sb.reverse(); // dlroW olleH

MCQ / One-Line Answers 1 mark each
Q1. Who is the father of Java?
1 mark▾
✅ James Gosling. Java was developed at Sun Microsystems in 1995. Original name was Oak.
Q2. What does JVM stand for and what is its role?
1 mark▾
✅ Java Virtual Machine. It executes Java bytecode, making Java platform-independent.
Q3. What is the default capacity of StringBuffer?
1 mark▾
✅ 16 characters. Default capacity of StringBuffer is 16.
Q4. Which loop guarantees at least one execution?
1 mark▾
✅ do-while loop. It checks condition after executing, so body always runs at least once.
Q5. Does Java support multiple inheritance through classes?
1 mark▾
✅ No. Java does NOT support multiple inheritance through classes. It is supported through Interfaces only.
Q6. What is the difference between break and continue?
1 mark▾
✅ break exits the loop entirely. continue skips the current iteration and moves to the next one.
Q7. Are Strings in Java mutable or immutable?
1 mark▾
✅ Immutable. Once created, a String's value cannot be changed. Any modification creates a new String object.
Q8. What is an array's index start value in Java?
1 mark▾
✅ 0 (zero). Arrays in Java are zero-indexed — first element is at index 0.
Q9. What keyword is used for inheritance in Java?
1 mark▾
✅ extends keyword. Example: class Dog extends Animal { }
Q10. What is bytecode in Java?
1 mark▾
✅ Bytecode is the intermediate code (.class file) generated by the Java compiler (javac). It is executed by the JVM and is platform-independent.
Short Answer Questions 2–5 marks
Q11. Explain the four main OOP concepts with examples.
5 marks▾
1. Encapsulation: Wrapping data and methods together. Example: Student class with private name and public getters/setters.

2. Inheritance: Child class inherits parent's properties. Example: Dog extends Animal — Dog gets eat() from Animal.

3. Polymorphism: Same action, different forms. Overloading = compile-time; Overriding = runtime.

4. Abstraction: Hiding implementation details. Abstract class or Interface used. ATM example — user sees buttons, not internal logic.
Q12. What is the difference between StringBuffer and StringBuilder?
3 marks▾
StringBuffer: Thread-safe, synchronized, slower. Used in multi-threaded environment.

StringBuilder: Not thread-safe, not synchronized, faster. Used in single-threaded environment.

Both are mutable alternatives to String, part of java.lang package.
Q13. Explain the types of loops in Java with syntax.
4 marks▾
1. while loop — pre-test, may not execute if condition is false initially
while(condition) { // body }
2. do-while loop — post-test, always executes at least once
do { // body } while(condition);
3. for loop — when number of iterations known
for(init; condition; increment) { }
4. for-each loop — traverse arrays/collections
for(type var : array) { }
Q14. What is a constructor? What are its types?
3 marks▾
A constructor is a special method that initializes an object when created. It has the same name as the class and no return type.

Types:
1. Default Constructor — No arguments. Java provides one if you don't define any.
class Car { Car() { } }
2. Parameterized Constructor — Accepts arguments for initialization.
class Car { Car(String model, int year) { } }
Q15. Explain byte streams and character streams.
3 marks▾
Byte Streams: Handle binary data (8-bit bytes). Key classes: InputStream, OutputStream, FileInputStream, FileOutputStream, BufferedInputStream.

Character Streams: Handle text data (16-bit Unicode characters). Key classes: Reader, Writer, FileReader, FileWriter, BufferedReader, BufferedWriter.
Long Answer / Essay Questions 5–10 marks
Q16. Explain all features of Java programming language in detail.
8 marks▾
Write about each feature with explanation:

1. Simple — Based on C++, removes complexity (no pointers, operator overloading)
2. Object-Oriented — Everything is object; supports class, object, inheritance, polymorphism etc.
3. Platform Independent — bytecode runs on any JVM ("Write Once, Run Anywhere")
4. Portable — bytecode is hardware/OS independent
5. Secured — No explicit pointers, sandbox environment
6. Robust — Strong memory mgmt, garbage collection, exception handling
7. Architecture Neutral — Primitive sizes fixed (int = 4 bytes always)
8. Multithreaded — Multiple threads share common memory
9. High Performance — bytecode close to native, JIT compiler
10. Interpreted — JVM interprets bytecode at runtime
Q17. What is inheritance? Explain all types with examples.
8 marks▾
Definition: Inheritance allows a class to acquire properties and methods of another class. Uses extends keyword.

Types:
1. Single — One parent, one child: A → B
2. Multilevel — Chain: A → B → C
3. Hierarchical — One parent, many children: A → B, A → C
4. Multiple — Not supported via classes in Java (supported via interfaces)
5. Hybrid — Combination of types (via interfaces)

Benefits: Code reusability, method overriding, hierarchical organization, easier maintenance
class Animal { void eat() { System.out.println("eating"); } } class Dog extends Animal { void bark() { } } Dog d = new Dog(); d.eat(); // inherited
Q18. Explain control statements in Java — if, switch, loops, break, continue.
10 marks▾
Categories:
1. Conditional/Selection — if, else, if-else ladder, switch
2. Iteration/Looping — while, do-while, for, for-each
3. Jump — break, continue

if-else: Executes block based on condition.
switch: Tests one variable against multiple cases. Needs break to prevent fall-through.
while: Pre-test loop — condition checked first.
do-while: Post-test loop — always runs at least once.
for: Used when iterations are known. Has init, condition, increment in one line.
for-each: Traverses array/collection automatically.
break: Exits loop or switch immediately.
continue: Skips current iteration, goes to next.
Q19. What are Arrays in Java? Explain types and important methods.
6 marks▾
Definition: Array is a container that holds fixed number of values of same type. Indexed from 0.

Types: Primitive arrays (int[]), Object arrays (String[]), Multidimensional (int[][]), Jagged arrays (varying row sizes)

Declaration:
int[] arr = new int[5]; // allocate int[] nums = {1, 2, 3}; // direct init
java.util.Arrays methods: sort(), binarySearch(), equals(), fill(), copyOf(), toString()
