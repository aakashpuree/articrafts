Unit 1
Java Fundamentals & OOP
HIGH PRIORITY
Features of Java
  • Simple — based on C++, no pointers
  • Object-Oriented — everything is an object
  • Platform Independent — bytecode + JVM
  • Portable — same bytecode on any JVM
  • Secured — sandbox, no explicit pointers
  • Robust — garbage collection, exception handling
  • Multithreaded — multiple threads in memory
  • Architecture Neutral — fixed primitive sizes
  • High Performance — bytecode near native code
OOP Pillars
  • Class — blueprint/template for objects
  • Object — instance of a class
  • Inheritance — child gets parent's properties
  • Polymorphism — same action, different ways
  • Abstraction — hide implementation, show features
  • Encapsulation — wrap data + methods together
Types of Inheritance
  • Single — one parent, one child
  • Multilevel — A → B → C
  • Hierarchical — one parent, many children
  • Multiple — NOT supported via classes (only interfaces)
  • Hybrid — combination (via interfaces)
class Child extends Parent { }
Polymorphism Types
  • Compile-time (Static) — Method Overloading
  • Runtime (Dynamic) — Method Overriding
int add(int a, int b)\ndouble add(double a, double b)\n\nclass Dog extends Animal {\n void sound() { }\n}
Abstraction
  • Abstract class → partial abstraction
  • Interface → 100% abstraction
  • ATM machine analogy
abstract class Animal {\n abstract void sound();\n void eat() { }\n}
Encapsulation
  • Wrap data + methods into a single unit
  • Use private fields + public getters/setters
private String name;\npublic String getName() { return name; }\npublic void setName(String n) { name = n; }
Java Platforms
  • Java SE — Standard, core APIs
  • Java EE — Enterprise, web apps
  • Java ME — Mobile/Micro edition
  • JavaFX — Rich Internet Applications
Java Program Flow
  • .java → javac → .class (bytecode)
  • JVM reads and executes bytecode
  • Entry point: public static void main(String[] args)

Unit 3
Java Classes, Constructors & Interfaces
HIGH PRIORITY
Class Declaration
access_modifier class ClassName {\n data member;\n method;\n constructor;\n}
  • Class = blueprint / template
  • Class does NOT occupy memory
  • Object occupies memory when created
Constructors
  • Same name as class, no return type
  • Called automatically when object is created
  • Cannot be abstract, static, final, synchronized
class Car {\n Car() { } // default\n Car(String m) { this.model = m; }\n}
Interface
  • Blueprint of class — only abstract methods
  • Achieves 100% abstraction
  • Supports multiple inheritance
  • Uses "implements" keyword
interface Animal {\n void eat();\n}\nclass Dog implements Animal {\n public void eat() { }\n}
Benefits of Inheritance
  • Code Reusability
  • Hierarchical Organisation
  • Polymorphism support
  • Easier Maintenance
Unit 4
Control Statements
HIGH PRIORITY
if / else / ladder
if (condition) {\n // true block\n} else if (cond2) {\n // another\n} else {\n // default\n}
switch
switch(expr) {\n case val1: break;\n case val2: break;\n default:\n}
Loops
  • while — pre-test (may not run)
  • do-while — post-test (runs at least once)
  • for — when iterations are known
  • for-each — iterate arrays/collections
break & continue
  • break — exits loop/switch immediately
  • continue — skips current iteration
Unit 5
Arrays
Array Basics
  • Fixed size, same data type
  • Indexed from 0
  • Homogeneous — all same type
int[] arr = new int[5];\nint[] nums = {1, 2, 3, 4, 5};
Arrays Class Methods
  • Arrays.sort(arr)
  • Arrays.binarySearch(arr, key)
  • Arrays.equals(a1, a2)
  • Arrays.fill(arr, val)
  • Arrays.copyOf(arr, len)
  • Arrays.toString(arr)
Array Types
  • Primitive arrays — int[], char[]
  • Object arrays — String[], Person[]
  • Multidimensional — int[][]
  • Jagged arrays — rows of different length

Q1. Who is the father of Java?
1 mark▾
✅ James Gosling. Developed at Sun Microsystems in 1995. Original name was Oak.
Q2. What does JVM stand for?
1 mark▾
✅ Java Virtual Machine. Executes Java bytecode, making Java platform-independent.
Q3. Default capacity of StringBuffer?
1 mark▾
✅ 16 characters.
Q4. Which loop guarantees at least one execution?
1 mark▾
✅ do-while loop. Checks condition after executing.
Q5. Does Java support multiple inheritance through classes?
1 mark▾
✅ No. Supported through Interfaces only.
Q6. Difference between break and continue?
1 mark▾
✅ break exits the loop. continue skips current iteration.
Q7. Are Strings mutable or immutable?
1 mark▾
✅ Immutable.
Q8. Array index start value?
1 mark▾
✅ 0 (zero).
Q9. Keyword for inheritance?
1 mark▾
✅ extends.
Q10. What is bytecode?
1 mark▾
✅ Intermediate code (.class file) generated by javac. Platform-independent.
Short Answer Questions 2–5 marks
Q11. Explain the four main OOP concepts with examples.
5 marks▾
1. Encapsulation: Wrapping data and methods together.

2. Inheritance: Child class inherits parent's properties.

3. Polymorphism: Same action, different forms. Overloading + Overriding.

4. Abstraction: Hiding implementation details.
Q12. StringBuffer vs StringBuilder?
3 marks▾
StringBuffer: Thread-safe, synchronized, slower.

StringBuilder: Not thread-safe, not synchronized, faster.
Q13. Types of loops in Java?
4 marks▾
1. while — pre-test
2. do-while — post-test (runs at least once)
3. for — known iterations
4. for-each — arrays/collections
Q14. What is a constructor? Types?
3 marks▾
Same name as class, no return type. Default: No arguments. Parameterized: Takes arguments.
Q15. Byte streams vs Character streams?
3 marks▾
Byte Streams: Binary data (8-bit). FileInputStream/OutputStream.

Character Streams: Text data (16-bit Unicode). FileReader/Writer.
Long Answer 5–10 marks
Q16. Explain all features of Java.
8 marks▾
Simple, OOP, Platform Independent, Portable, Secured, Robust, Architecture Neutral, Multithreaded, Interpreted, High Performance
Q17. Inheritance types with examples?
8 marks▾
Single, Multilevel, Hierarchical, Multiple (via interface), Hybrid. No multiple inheritance via classes.
Q18. Explain control statements.
10 marks▾
Conditional: if, else, switch. Iteration: while, do-while, for, for-each. Jump: break, continue.
Q19. Arrays in Java?
6 marks▾
Fixed size, same type, zero-indexed. Types: Primitive, Object, Multidimensional, Jagged. Methods: sort, binarySearch, equals, fill, copyOf, toString.
